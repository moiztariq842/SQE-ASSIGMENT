## Findings (behaviour worth reporting)
1. **Bug:** `Stack(-1).is_full()` returns `False`, yet `push()` raises `StackOverflowError`. Captured as `xfail` in `TestIsFull`; it becomes a failure if upstream fixes it (`xfail_strict = true`), which tells you to remove the marker.
2. `CircularQueue.first()` returns `False` (not `None`) on an empty queue.
3. `CircularQueue(-1)` is silently accepted and behaves like capacity 0 (`[None] * -1 == []`).
4. `is_prime(True)` returns `False`, because `bool` is an `int` subclass (True == 1).
